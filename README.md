# VAULT — как опубликовать веб-приложение

В архиве 3 файла — их нужно держать вместе, в одной папке:

- `index.html` — само приложение (всё внутри одного файла)
- `manifest.json` — делает сайт «устанавливаемым» на телефон, как настоящее приложение
- `favicon.svg` — иконка

## Хранение данных

Все твои данные (баланс, задачи, цели, игры и т.д.) сохраняются прямо в браузере на твоём телефоне/компьютере (localStorage). Ничего не уходит на сервер. Если очистить данные браузера — приложение "забудет" всё, поэтому периодически делай **Настройки → Экспорт данных**, чтобы иметь резервную копию.

## Как опубликовать (бесплатно, без кода)

### Вариант 1 — Netlify Drop (проще всего)
1. Зайди на **app.netlify.com/drop**
2. Перетащи туда папку с этими тремя файлами
3. Через 10 секунд получишь ссылку вида `https://random-name.netlify.app`
4. Открой её на телефоне → в браузере выбери «Добавить на экран Домой» — получится иконка как у настоящего приложения

### Вариант 2 — GitHub Pages
1. Создай новый репозиторий на GitHub
2. Загрузи туда эти 3 файла (Add file → Upload files)
3. Settings → Pages → Source: выбери ветку `main` → Save
4. Через минуту сайт будет доступен по ссылке вида `https://твой-логин.github.io/название-репозитория/`

### Вариант 3 — Vercel
1. Зайди на **vercel.com** → New Project → Deploy без Git (можно перетащить папку)
2. Получишь ссылку сразу после загрузки

## Установка на телефон как приложение

**iPhone (Safari):** открой ссылку → кнопка «Поделиться» → «На экран «Домой»»
**Android (Chrome):** открой ссылку → меню (три точки) → «Добавить на главный экран» / «Установить приложение»

После этого VAULT будет открываться как обычное приложение — без адресной строки браузера, с собственной иконкой.

## Если захочешь дорабатывать код

Весь код — в `index.html`, внутри тега `<script type="text/babel">`. Он написан на React и работает прямо в браузере без сборки (React, Babel и Tailwind CSS подключены через CDN). Можно открыть файл в любом текстовом редакторе и менять напрямую.
